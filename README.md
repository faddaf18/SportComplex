# Спортивный комплекс (Sport Complex Management System)

## 📌 О проекте
Программная система для автоматизации и управления деятельностью спортивного комплекса (Вариант 28). Проект разработан на языке C++ с применением принципов объектно-ориентированного программирования (ООП), современных стандартов безопасности и чистого кода.

## Предметная область и сущности
Согласно варианту задания, система моделирует ключевые процессы спортивного комплекса:
* **Спортивные объекты (залы и площадки):** хранят информацию о названии, типе, максимальной вместимости и перечне доступных видов спорта.
* **Тренеры:** обладают персональными данными и специализациями по видам спорта.
* **Спортсмены:** пользователи системы, которые могут записываться на тренировки.
* **Группы и тренировки:** система осуществляет жесткий контроль за соблюдением лимитов вместимости групп и проверку соответствия специализации тренера выбранному виду спорта.

## 🛠 Технологии
* **Язык:** C++ (стандарт C++17 и выше)
* **Инструменты:** Сборка в Visual Studio, контроль версий Git.
